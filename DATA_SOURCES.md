## HSK vocabulary (`data/decks/hsk/*.json`)

Generated by `scripts/build_hsk_decks.py` from:

* **[drkameleon/complete-hsk-vocabulary](https://github.com/drkameleon/complete-hsk-vocabulary)**
  (MIT License, © Yanis Zafirópulos). Provides `complete.json`: simplified hanzi, HSK level,
  numeric pinyin, and English meanings for every HSK 2.0/3.0 word.

That project itself compiles data from several upstream sources, credited in its own README:

* HSK 2.0 wordlists: [clem109/hsk-vocabulary](https://github.com/clem109/hsk-vocabulary)
* HSK 3.0 wordlists: [elkmovie/hsk30](https://github.com/elkmovie/hsk30)
* **English definitions: [CC-CEDICT](https://cc-cedict.org/)** (MDBG), licensed
  [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). This is a share-alike license:
  if you redistribute this dictionary data (as-is or modified), you must credit CC-CEDICT and
  license that data under the same terms. That applies to the `meaning` field of every HSK card
  here, but not to Hànyǔ's own code.
* Radicals: [skishore/makemeahanzi](https://github.com/skishore/makemeahanzi) (`dictionary.txt`)
* Frequency data: [krmanik/HSK-3.0-words-list](https://github.com/krmanik/HSK-3.0-words-list)

### Build notes

`complete.json` is not committed to this repo (see `.gitignore`); download it yourself:

bash

```bash
curl -o data/sources/hsk/complete.json \
    https://raw.githubusercontent.com/drkameleon/complete-hsk-vocabulary/main/complete.json
python scripts/build_hsk_decks.py
```

Words with more than one genuine pronunciation (真 polyphones, e.g. 的/了/和) are intentionally
left out of the pinyin-quiz decks and logged to `data/sources/hsk/skipped.json`, since the source
doesn't reliably indicate which reading is "primary". They're candidates for hand curation in the
Phase 4 hanzi work, where each reading can be entered deliberately. See the script's docstring for
the full skip criteria.

Levels 7-9 (`new-7`, HSK 3.0's merged advanced band) are not currently built - it's a very large
list (5,600+ words) and out of scope for a travel-focused MVP. Re-run the script with `LEVELS`
extended if you want it later.

## Travel decks (`data/decks/travel/*.json`)

Hand-written for this project. No external data source. Worth a native-speaker check before
relying on them while actually traveling.
